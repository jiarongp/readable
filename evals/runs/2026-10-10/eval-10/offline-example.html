The Line y=x+1y = x + 1

2026-10-10 · 3 min read · explainer with hypothetical examples

The equation y=x+1y = x + 1 is a rule for turning one number into another: take xx, add one, and call the result yy. Every pair of numbers that obeys the rule is a point, and all of those points together form a straight line.

This note works through the rule with two hypothetical examples, x=0x = 0 and x=2x = 2, then draws the line and lets you slide xx between those values to watch a point move along it. The equation and the drawing are plain HTML, so they read without JavaScript; only the slider needs it.

The rule: add one to xx

Whatever xx is, yy is one more:

y=x+1y = x + 1

Here xx is the input, a number you choose, and yy is the output, the number the rule gives back. The right-hand side, x+1x + 1, says exactly what happens to the input: the only operation is adding 1.

Because nothing multiplies or divides xx, the rule never stretches or shrinks a change. If xx goes up by some amount, yy goes up by the same amount. The two examples below show this with actual numbers.

Two examples: x=0x = 0 and x=2x = 2

Take x=0x = 0 first, a value chosen only for illustration. Adding one gives 0+1=10 + 1 = 1, so y=1y = 1. The pair (0, 1) is one point that satisfies the rule.

Now take x=2x = 2. Adding one gives 2+1=32 + 1 = 3, so y=3y = 3, and the pair (2, 3) is a second point.

Compare the two rows: moving xx from 0 to 2 moved yy from 1 to 3. The input went up by 2, and so did the output. That equal change is why the picture below is a straight line rising at 45 degrees when both axes use the same spacing per unit.

The picture: a line through both examples

The figure plots xx across and yy up, with the same spacing per unit on both axes. The two examples sit at (0, 1) and (2, 3) as hollow circles, and the line through them is y=x+1y = x + 1. A filled circle marks a third value, x=1x = 1, where the rule gives 1+1=21 + 1 = 2, so that point sits at (1, 2), midway between the examples.

Two features of the line come straight from the equation. Where the line crosses the vertical axis, x=0x = 0 and so y=1y = 1; the +1+1 in the rule is the height of that crossing. And the line climbs one unit for every unit it moves right, because adding a constant leaves the size of a change in xx unchanged when it reaches yy.

Sliding xx along the line

The slider under the figure sets xx anywhere from 0 to 2 in steps of 0.1. As you drag it, the readout recomputes y=x+1y = x + 1 and the marked point slides along the line, with its guides following. At x=0x = 0 the point lands on the first example, (0, 1); at x=2x = 2 it lands on the second, (2, 3).

Every stop in between also lies on the line, and that is the point of the picture. The rule holds for every xx, not only the two values we checked by hand.
