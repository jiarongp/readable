What the example says

In the hypothetical example given by Example Author (2024), selecting a larger batch reduced the update frequency. A batch is the set of training examples the model processes before it changes its parameters once. Update frequency is how often those parameter changes happen.

The source text does not say how update frequency was measured, for example per pass over the training data or per unit of time. It also reports no effect on training speed, final accuracy, or anything else. Because the example is hypothetical, it describes a scenario rather than a measured training run.

Why a larger batch means fewer updates per pass

For a fixed dataset and one pass over it, the number of updates is the dataset size divided by the batch size, so a larger batch gives fewer updates per pass. This follows from the definitions above; it is not a finding from the source. The table shows the arithmetic with made-up numbers.
