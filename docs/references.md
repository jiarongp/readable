# References

Literature consulted for the `readable` skill's writing rules, and what each
one contributed. Newest additions at the bottom.

## Foundations of the skill

- **ASD-STE100 Simplified Technical English** (ASD, technical writing standard).
  The origin of the core style rules: one idea per sentence, active voice,
  one term per concept, short paragraphs. The skill applies the writing
  rules, not the restricted dictionary.
  <https://www.asd-ste100.org/>

## Context, density, and document structure

- **ASD-STE100 FAQ** (ASD Simplified Technical English Maintenance Group).
  Explains the writing rules and controlled dictionary, including technical
  nouns and verbs. The skill borrows language principles; it does not enforce
  the dictionary or claim STE compliance.
  [Official FAQ](https://www.asd-ste100.org/STE_faq.html)

- **Write accessible documentation** (Google developer documentation style guide).
  Supports manageable sentences, acronym definitions, descriptive headings,
  and putting important information first. Its recommendation to use fewer
  than 26 words per sentence is a review signal in this skill, not a limit.
  [Accessibility guidance](https://developers.google.com/style/accessibility)

- **Cross-references and linking** (Google developer documentation style guide).
  Supports providing necessary context in the document rather than sending
  the reader elsewhere to understand the current explanation.
  [Cross-reference guidance](https://developers.google.com/style/cross-references)

- **Use simple words, concise sentences** (Microsoft Style Guide).
  Supports familiar, direct vocabulary. The skill retains specialized terms
  when plain alternatives would lose precision.
  [Word-choice guidance](https://learn.microsoft.com/en-us/style-guide/word-choice/use-simple-words-concise-sentences)

- **Scannable content** (Microsoft Style Guide).
  Supports short, descriptive headings, focused paragraphs, and clear document
  organization. The skill balances brevity with the reasoning a reader needs.
  [Scannable-content guidance](https://learn.microsoft.com/en-us/style-guide/scannable-content/)

The reader model, accuracy priorities, context rules, and the writing workflow
are stated in [skill/SKILL.md](../skill/SKILL.md), which is the authoritative
statement of the rules.
